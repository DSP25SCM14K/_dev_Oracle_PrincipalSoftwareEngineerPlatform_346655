# Dev Kumar — Database Platform & Reliability Portfolio

A responsive engineering portfolio featuring an animated Oracle database fleet topology, RAC and Data Guard reliability story, full experience history, and project links.

Open `index.html` directly or serve this folder with a static web server. GitHub Pages publishes the repository root with the included Actions workflow.

- `index.html` — portfolio content and database fleet diagram
- `styles.css` — responsive design and animation
- `script.js` — animated topology background, rotating focus text, reveals, and project search
